## [古 DNA 研究发现近期人类广泛定向选择](https://www.nature.com/articles/s41586-026-10358-1) ⭐️ 9.0/10

一篇发表于《自然》的论文分析了 15,836 个古代西欧亚人基因组，其中包括 10,016 个新样本，并估计了过去一万年间 970 万个变异位点的选择系数。作者报告称，定向选择并非罕见而是广泛存在，相关等位基因频率变化与现代人较低的预测体脂和精神分裂症风险，以及更高的认知相关指标有关。 这项研究挑战了人类进化遗传学中的一个长期观点，即近期强烈的定向选择并不常见；相反，它表明自然选择塑造的位点和复杂性状可能远比过去认为的更多。它还说明，大规模古 DNA 时间序列不仅能重建人群历史，也能直接检验进化如何影响现代人类生物学。 根据《自然》论文介绍，该方法检验等位基因频率是否在时间上呈持续一致的变化趋势，同时控制群体结构，从而应对区分自然选择与迁徙或人口学变化这一核心难题。该研究聚焦于西欧亚，因此其结论首先适用于这一地区；此外，关于性状的推断基于遗传关联，而不是对古代个体表型的直接测量。

telegram · zaihuapd · Apr 17, 18:00

**背景**: 古 DNA 研究通过比较不同时代人群的基因组，让研究者能够直接观察等位基因频率在数千年中的变化，而不必只依赖现代人群去反推过去。定向选择是指某些影响繁殖成功的变异，其频率持续上升或下降，但在人类历史中，这种趋势很容易与迁徙和人群混合造成的变化相混淆。西欧亚较早的古基因组选择扫描曾发现一些典型案例，但由于样本规模有限，研究者很难判断这一过程到底有多普遍。本文利用更大的数据集和专门的统计框架，在全基因组尺度上重新检验了这个问题。

## [iTerm2 让查看文本也可能变危险](https://blog.calif.io/p/mad-bugs-even-cat-readmetxt-is-not) ⭐️ 8.0/10

一篇安全分析文章表明，iTerm2 可能被嵌入文件内容中的恶意转义序列利用，因此即使只是执行 `cat readme.txt`，终端在渲染输出时也可能触发不安全行为。该问题与 iTerm2 对终端控制序列的处理有关，而且文章指出在披露时修复尚未进入稳定版本。 这很重要，因为终端模拟器是开发者高度信任的工具，而很多人默认显示一个文本文件是无害的。如果终端输出本身就能成为攻击面，那么开发者、运维人员以及任何查看不受信任日志或仓库文件的人，都可能在日常流程中遭遇钓鱼、界面欺骗甚至更严重的风险。 iTerm2 支持许多专有转义码，包括基于 OSC 的文件、图像以及其他富交互功能，而且其官方文档也警告这些序列可能产生未知效果，应谨慎使用。这类问题并不只属于内存安全范畴：终端解析器和功能丰富的集成能力本身就可能出现逻辑缺陷，使得渲染攻击者可控文本时触发非预期操作。

hackernews · arkadiyt · Apr 17, 18:43

**背景**: 终端模拟器会解析直接嵌入文本流中的 ANSI 等转义序列，从而让程序能够修改颜色、移动光标、设置标题，或者调用模拟器特有功能。iTerm2 又在这一机制上增加了专有转义码，例如 OSC 1337，以提供更丰富的能力；这虽然提升了便利性，但如果显示了不受信任的内容，也会扩大攻击面。安全研究人员过去已经多次证明，终端可因转义序列处理而被滥用，其中既包括更早的 iTerm2 问题，也包括其他终端模拟器在 URL 或命令处理上的漏洞。

## [NIST 收缩 NVD 的 CVE 增强工作](https://risky.biz/risky-bulletin-nist-gives-up-enriching-most-cves/) ⭐️ 8.0/10

据报道，NIST 正在调整 National Vulnerability Database 对 CVE 记录的处理方式，不再像过去那样为大多数条目普遍补充详细元数据和评分。根据 NIST 的最新说明，今后它只会对符合特定条件的部分 CVE 进行增强，而更多评分和记录细节将由厂商及其他 CVE 签发方提供。 这改变了漏洞管理工具、防御团队以及下游数据库长期依赖的一项核心输入，即由 NVD 提供的标准化严重性评分和元数据。如果由厂商和其他签发方直接提供更多这类信息，生态系统在某些情况下可能会获得更快覆盖，但也会带来更大的不一致性、利益冲突以及对严重性评分可信度的担忧。 NIST 表示，这一调整与 CVE 数量创纪录增长有关，有报道称漏洞提交通量激增了 263%，使得对每条记录都进行完整增强越来越难以持续。按照 NVD 的术语，“增强”是指在基础 CVE 记录之外补充 CVSS 严重性指标、受影响产品数据以及其他分析信息。

hackernews · mooreds · Apr 17, 15:09

**背景**: CVE 是公开披露软件漏洞的标准标识体系，而 CVE Numbering Authorities（CNA）是被授权分配 CVE ID 并发布 CVE 记录的组织。由 NIST 运营的 NVD 历来会在这些 CVE 记录基础上进行增强，补充额外分析，包括 CVSS 严重性评分和安全工具常用的其他元数据。CVSS 是一种被广泛采用的评分框架，会给漏洞分配 0 到 10 的数值严重性分数，但它长期以来一直存在争议，因为同一个漏洞会因具体环境和评分选择不同而得到不同解读。

**背景**: 在关于自主武器的讨论中，“human in the loop”通常是指人类必须参与或授权武器的行动，而“human on the loop”通常是指人类监督一个能够自行行动的系统。美国国防部政策曾将自主武器系统定义为：一旦启动，就可以在没有进一步人工干预的情况下选择并攻击目标。近期研究和政策分析还区分了自主武器系统与用于军事目标指示的 AI 决策支持系统，因为即便后者并不直接发射武器，它们也可能影响生死攸关的决定。

## [能源冲击下中国清洁技术出口猛增](https://financialpost.com/pmn/business-pmn/china-clean-tech-exports-jump-amid-global-energy-disruption) ⭐️ 7.0/10

受中东紧张局势引发的全球能源扰动影响，中国清洁技术产品在 3 月份出口显著增长，替代能源相关产品需求明显上升。报道援引海关数据显示，太阳能电池出口同比增长 80%，电动车出口增长 53%，锂离子电池出口增长 34%。 这些数据表明，化石能源市场受到地缘政治冲击时，太阳能、电池和电动车的需求可能被进一步推高，清洁技术正在同时成为能源安全和国际贸易的重要议题。这也凸显出，中国凭借既有制造规模，正在全球多国寻求能源替代之际进一步巩固其在清洁技术供应链中的地位。 报道中增幅最大的是太阳能电池，这一环节位于光伏产业链中游，介于上游硅料、硅片与下游组件、应用系统之间。这篇消息本质上是一次简短的贸易动态更新，而不是完整的市场研究，因此它说明了 3 月份出口动能强劲，但并不能单独证明这一增势会长期持续。
